On a Manufacturing Order's Components tab, a "Fixed Qty" column is
available (enable it from the column selector if it isn't shown). Check it
on any component whose demand should stay exactly as entered regardless of
future changes to the order's quantity to produce.

Components added directly on the order, without picking them from the
Bill of Materials, are flagged this way automatically -- uncheck the box
on any of them if that particular one should actually scale with the
quantity produced.
